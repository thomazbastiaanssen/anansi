# Simplified snippet of the Krebs cycle

Enzymes and metabolites that make up the Krebs cycle. Features share a
row when they play a role in the same reaction. Used in vignettes,
exported to facilitate user exploration.

## Usage

``` r
data("krebs", package = "anansi")
```

## Format

A `data.frame` of two factors, named `"Enzyme"` and `"Metabolite"`,
which contain these respective components of the krebs cycle.

## Source

Generated by hand based on the krebs cycle.
