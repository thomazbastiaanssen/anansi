# Snippet of the CLR-transformed inferred functional data from the FMT Aging study.

Piphillin was used to infer functions from the 16S sequencing data in
terms of KOs. Unfortunately, the Piphillin algorithm is proprietary and
has since been taken down.

## Usage

``` r
data("FMT_data", package = "anansi")
```

## Format

A marix object with 6468 rows, KOs, and 36 columns, samples.
