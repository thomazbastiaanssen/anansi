# Snippet of the metadata from the FMT Aging study.

There were three treatment groups in the study that all received faecal
microbiota transplantation (FMT). Young mice that received FMT from
young mice (Young yFMT), aged mice that received FMT from aged mice
(Aged oFMT) and aged mice that received FMT from young mice (Aged yFMT).

## Usage

``` r
data("FMT_data", package = "anansi")
```

## Format

A data.frame object with 36 rows, samples, and two columns, denoting
sample ID and treatment group, respectively.
