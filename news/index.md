# Changelog

## anansi 0.99.0

Submission to Bioconductor

## anansi 0.7.7

MOVED TO S7 CLASS SYSTEM

- anansi has been fully ported to the recent S7 framework. This change
  should not affect output or functionality.

## anansi 0.7.0

NEW FEATURES

- Added the MultiFactor S4 class, which keeps track of relational data
  for us. MultiFactor is also used under the hood in
  [`weaveWeb()`](https://thomazbastiaanssen.github.io/anansi/reference/weaveWeb-generic.md).

DOCUMENTATION

- A general vignette and two more in-depth vignettes are now available
  as developed drafts.

## anansi 0.6.0

NEW FEATURES
